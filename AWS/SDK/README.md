#	AWS SDK実行検証

AWS SDKの実行検証結果を下記に記載する。


## AWS SDK事前準備

(1)	VSCode（Visual Studio Code）を起動する。

(2)	Pythonをインストールする。
 

(3)	VSCodeのメニューから「ターミナル」 > 「新しいターミナル」を選択して、ターミナルをクリックする。

(4)	ターミナルで、「pip install boto3」を実行する。
※boto3をインストールする。
 

(5)	「aws configure」を実行する。
